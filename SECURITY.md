# Security boundary

The reference implementation is trusted local code. It is a library, not a network service. It has no authentication, access control or tenant isolation. A capability declaration states functional availability. It is not authentication.

The store keeps rule companions, emitter artifacts and receipts as opaque bytes. It never loads, imports, evaluates or executes them. The conformance runner loads only the adapter module that its caller names. A validator that an application gives to `publish` is the code of that application.

Use neutral data when you report a problem. For a possible vulnerability, use GitHub private vulnerability reporting. Do not post sensitive payloads or exploit details in a public issue. No response time is promised.
